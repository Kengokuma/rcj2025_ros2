# rcj2025_ros2
RoboCup Junior Kansai Open Competition 2025 Team "Remember" ROS2 Software

### operating environment
- Ubuntu 24.04 LTS
- ROS 2 Jazzy

### development rule
- Function implementation is done in branch, then pull request is submitted and merged into main
- Nodes follow the principle of single responsibility, one node, one function
- One main function in a package, separate packages if multiple functions are to be implemented.
- Package naming convention is catch2025_xxx (where xxx is the prefix of the package feature ex: interface, msg, bringup, etc.)
- The executable name must end with _node
- The node implementation is divided into source (cpp) and headers (hpp), and executables are generated using rclcpp_components
- Once the node is implemented, document the interface (topic/service name, type, content) and parameters in the package doc directory

### Repository Clone
```
git clone --recursive https://github.com/Kengokuma/rcj2025_ros2.git
```

### Dependency Setup
```
rosdep update
rosdep install --from-paths . --ignore-src -r -y
```

### build
```
colcon build --symlink-install
```

### test
```
source install/setup.bash
colcon test --event-handlers console_direct+ --return-code-on-test-failure
```

### build cache clear
```
rm -rf build/ install/ log/
```
### How to start the system
```
source install/setup.bash
ros2 launch rcj2025_bringup rcj2025.launch.py
